# Week 1 Reflection

Reflect 1: What counts as “making” in the age of AI? What might be gained/lost when machines participate in making? 
In the age of AI, “making” doesn’t really mean doing everything by yourself anymore. It’s more about guiding the process and making decisions along the way. Even if a machine is doing a lot of the work, people are still the ones deciding what’s important and how the final result should look or be used. AI can actually be really helpful because it lets you see patterns faster, try out more ideas, and get things done in less time. This can make creating things feel more efficient and open up more possibilities than before. At the same time, there are some downsides. Using AI can take away some of the human touch or make you pay less attention to small details that matter. Since AI depends a lot on data that already exists, the things it produces might not feel as original or unique. Sometimes it can feel like you’re just remixing what’s already out there instead of creating something completely new. Because of this, “making” with AI feels more like a shared process between humans and machines. People still come up with the ideas and set the direction, while AI helps carry those ideas out. In the end, it’s kind of like working with a tool that’s really powerful, but still needs human input to make something meaningful.
