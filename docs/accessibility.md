# Accessibility

## How I improved accessibility
This site is built to be readable and easy to navigate without extra clicks or hidden menus. I kept the navigation bar consistent across pages (Home, Projects, Curriculum, About, AI & Ethics, Reflections, Accessibility) so visitors can move around the portfolio quickly. I also wrote short paragraphs and used clear section headings to help screen readers and skimmers understand structure. Every image in my project pages includes alt text that explains what the viewer would miss if the image doesn’t load, including the headshot on the homepage and the visuals in the weekly “makes.” I chose a clean, readable font and kept color contrast strong across light and dark modes so the text stays legible in different lighting conditions. Because I use a lot of image-based projects (Canva graphics, maps, and a network diagram), I’m careful to describe the visual meaning in the surrounding text, not just in captions.

## Ongoing checks
As I add new work, I re-check headings to keep them in order (H1 → H2 → H3), verify that links are descriptive, and make sure key pages like Projects and Reflections remain easy to find from the top navigation.
