# Accessibility

## Goals
I aim to make the site simple, clear, and easy to follow for a wide range of readers.

## What I focus on
- Plain language and short paragraphs
- Clear headings and consistent structure
- Easy-to-scan lists where possible

## Ongoing improvements
I’ll keep checking for clarity, readability, and layout issues as I add new content.
