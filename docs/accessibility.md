# Accessibility

## Goals
I aim to make the site simple, clear, and easy to follow for a wide range of readers. I want content to be readable on phones and laptops, with a layout that does not depend on color alone.

## What I focus on
- Plain language and short paragraphs
- Clear headings and consistent structure
- Easy-to-scan lists where possible
 - Alt text for images so key visuals are described
 - Links that are descriptive and easy to identify

## Ongoing improvements
I’ll keep checking for clarity, readability, and layout issues as I add new content. If something is hard to navigate or read, I will update it.
